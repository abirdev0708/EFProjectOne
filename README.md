# EFProjectOne — Task Tracker API

A simple Task Tracker REST API built with **ASP.NET Core Minimal APIs** and **Entity Framework Core**, backed by **SQL Server**. Built as a hands-on learning project to practice EF Core Code-First workflows, migrations, and querying.

## Tech Stack

- **.NET 8 (LTS)**
- **ASP.NET Core Minimal APIs**
- **Entity Framework Core 8** with the SQL Server provider
- **SQL Server** (running locally via Docker)
- **Swagger / Swashbuckle** for interactive API documentation

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Docker](https://docs.docker.com/get-docker/) (for running SQL Server locally)
- `dotnet-ef` CLI tool, pinned to match the project's EF Core version:
  ```bash
  dotnet tool install --global dotnet-ef --version 8.0.11
  ```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abirdev0708/EFProjectOne.git
cd EFProjectOne
```

### 2. Start SQL Server in Docker

```bash
docker run -e "ACCEPT_EULA=Y" \
  -e "MSSQL_SA_PASSWORD=YourStrong@Passw0rd1" \
  -e "MSSQL_PID=Developer" \
  -p 1433:1433 \
  -v mssql-data:/var/opt/mssql \
  --name sql-dev \
  --restart unless-stopped \
  -d mcr.microsoft.com/mssql/server:2022-latest
```

Verify it's up:
```bash
docker logs sql-dev
```
Look for `SQL Server is now ready for client connections`.

### 3. Configure the connection string

This project reads its connection string from **user secrets** rather than committing it to source control.

```bash
dotnet user-secrets init
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=localhost,1433;Database=TaskTrackerDb;User Id=sa;Password=YourStrong@Passw0rd1;TrustServerCertificate=True;"
```

Adjust the password to match whatever you used in the `docker run` command above.

### 4. Restore packages and apply migrations

```bash
dotnet restore
dotnet ef database update
```

This creates the `TaskTrackerDb` database and the `Tasks` table.

### 5. Run the API

```bash
dotnet run
```

The console will print the listening URL, e.g.:
```
Now listening on: http://localhost:5236
```

### 6. Try it out

Open Swagger UI in your browser:
```
http://localhost:5236/swagger
```

## API Endpoints

| Method | Route                     | Description                     |
|--------|----------------------------|----------------------------------|
| GET    | `/tasks`                   | Returns all tasks               |
| POST   | `/tasks`                   | Creates a new task              |
| PUT    | `/tasks/{id}/complete`     | Marks a task as complete        |

### Example: Create a task

**POST** `/tasks`
```json
{
  "title": "Learn EF Core",
  "isComplete": false
}
```

> Note: don't include `id` or `createdAt` in the request body — `id` is auto-generated by the database, and `createdAt` defaults to the current UTC time.

## Notes

- EF Core packages are pinned to `8.0.11` to stay aligned with the .NET 8 target framework — avoid bumping to a version that targets .NET 9/10 without also upgrading the project's target framework.
- The database schema is managed entirely through EF Core migrations — run `dotnet ef migrations add <Name>` after any model change, followed by `dotnet ef database update`.
